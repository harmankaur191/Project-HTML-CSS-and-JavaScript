## Development Process

Started off by writing basic HTML and CSS code to bring the UI. Then I worked on LeafLet to set up map view in script.js. I used the instruction guide to set up the map view followed by generating an geo.ipify API key to make fetch request and receive the response followed by setting lattitude and longitude values in mapview to reflect the location of the IP address.

## Challenges and solutions
Understanding and working with LeafLet was quite challenging. However, the guide did help and provided clarity. I did extra research too to undertandand implement it. Additionally, passing the data through export or parameter was complicated which I figured out after trying different ways.
Achieving the responsive UI was bit difficult but after spending sometime it worked out.
